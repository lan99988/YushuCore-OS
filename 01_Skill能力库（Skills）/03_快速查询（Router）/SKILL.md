## 功能定位

轻量级只读查询。处理一句话的进度/任务/统计查询。**只读不写**，不触发排程，不创建任务，不修改任何数据。

用户输入不含 `#` 前缀，且为纯查询："完成率""今天还有几个""最近一周"。

## 输入

自然语言查询。

## 输出

格式化文本报告（不写库）。

## 纲要

轻量级只读查询 skill。处理一句话的进度/任务/统计查询。
**只读不写**，不触发排程，不创建任务，不修改任何数据。
查询结果直接返回文本给用户。

## 触发

用户输入**不包含 `#` 前缀**，且内容是以下类型的**纯查询**：
- 进度查询："数学学到哪了""英语完成率""408进度"
- 任务查询："今天还有几个""这周完成了多少""有哪些硬骨头"
- 统计查询："这周任务完成率""最近一周完成了多少"
- 通用查询："看看今天安排""帮我查一下"

⚠️ **如果是"非查询"的每日安排/时间轴请求**（"帮我排一下今天"），应加载「每日排程算法」。

## 输出

直接返回格式化的文本报告。不产生结构化数据，不写库。

## 后续流程

查询完即结束，无下游 skill。

## 一、查询类型识别

| 关键词 | 查询类型 | 数据来源 |
|--------|---------|---------|
| 完成率 / 进度 / 到哪了 / 多少% | 科目进度 | 科目进度基线表 |
| 今天 / 今日 / 待办 / 还没做 | 今日任务 | 执行库 |
| 本周 / 这周 / 最近7天 | 本周统计 | 执行库 |
| 最近N天 / 过去N天 | 自定义统计 | 执行库 |
| 硬骨头 / 难啃 | 硬骨头查询 | 执行库 |
| 灵感 / 未处理 / 待孵化 | 灵感查询 | 灵感库 |
| 财务 / 花了多少 / 支出 | 财务查询 | 财务流水表 |
| 社交 / 好久没联系 / 生日 | 社交查询 | 社交关系表 |

## 二、各查询实现

### 2.1 科目进度查询

```bash
lark-cli base +record-list \
  --base-token=TtzIboiQQaPgfVszO2vc56wLnof \
  --table-id=tblQnjCO03WjQ7GC \
  --as=user \
  --limit=20 \
  --format=json
```

输出示例：
```
📊 各科进度一览：
  · 数学：45.2%（目标：1800题，已做813题）
  · 英语：38.0%（目标：考研词汇5500词，已背2094词）
  · 政治：12.5%
  · 408：30.1%
```

### 2.2 今日任务查询

```bash
lark-cli base +record-list \
  --base-token=TtzIboiQQaPgfVszO2vc56wLnof \
  --table-id=tblNQCB4pn6Rso4a \
  --as=user \
  --limit=200 \
  --format=json
```

过滤条件：截止日=今天 且 状态≠已完成

输出示例：
```
📋 今日待办（5项未完成）：
  ⭐ 数学2010真题 [120min] ⚡高
  · 英语阅读真题 [90min] ⚡高

✅ 已完成：3项 | 完成率：37.5%
```

## 三、阅读模式处理

当用户只说一个词或简短描述（如"查一下""看看""今天"），主动确认查询目标：

```
用户：今天
→ 你是指查看今天有哪些待办任务，还是今天的学习进度？
```
