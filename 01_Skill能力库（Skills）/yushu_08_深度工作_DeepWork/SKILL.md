## 功能定位

将《深度工作》6 大框架落地为飞书系统：深度规划 / 记录 / 复盘、第一勺冰淇淋、4DX、浮浅预算、环境隔离、ART 恢复、注意力审计。

## 触发方式

`#深度规划` / `#深度记录` / `#深度` / `#复盘深度` / `#注意力审计` / `【冲刺】` 标签 / `【深度：N】` 标签。

## 输入

`#深度*` 指令 + 变量。

## 输出

深度工作追踪表记录；复盘周报；每日推送模块。

## 依赖

- 飞书 Base（深度工作追踪表）
- input_parser（路由）
- daily_scheduler（每日模块）
- weekly_deep_review（周报）

## 数据

深度工作追踪表；runtime/_deep_work_plan.json、_overflow_tracker.json。

## 权限

- read：深度表
- write：深度表 + runtime
- admin：无

## 调用链

`#深度*` → input_parser → 飞书 Base 深度表；daily_scheduler / weekly_deep_review 读取

## 指令参考

### 深度工作指令

```
#深度规划 深度4小时 浮浅控制30%
  → 设定今日深度工作目标和浮浅预算

#深度记录 深度3.5小时 心流高 干扰1次 恢复活动：散步20min 第一勺完成
  → 记录当天深度工作表现（含恢复活动和第一勺状态）

#深度 今天状态好 冲刺3个
  → 通用入口，自动判断是规划还是记录

#复盘深度 7
  → 过去7天深度工作专项复盘（含模式识别+职场资本评估）

#注意力审计
  → 三步倒推法审视社交媒体使用
```

### 冲刺任务

```
#任务 完成高数第三章 【冲刺】 【项目：数学二】
  → 创建罗斯福冲刺任务，自动：精力=高, 耗时=30分钟
```

### 深度分标签

```
#任务 做数学真题 【深度：8】 【项目：数学二】【耗时：120分钟】
  → 标记任务的深度等级(1-10)，影响排程优先级
```

## 数据流（v2）

```
用户输入 ──#深度规划──→ input_parser.py ──→ runtime/_deep_work_plan.json
          ──#深度记录──→ input_parser.py ──→ 飞书Base深度工作追踪表（含恢复活动+第一勺）
          ──#复盘深度──→ input_parser.py ←── 飞书Base深度工作追踪表（+模式识别+职场资本）
          ──#注意力审计──→ input_parser.py ──→ 三步倒推法引导

daily_scheduler.py
  ├── compute_4dx_scoreboard() ←─ 读取深度工作追踪表(本周)
  ├── 第一勺冰淇淋 ←─ 从核心事件提取
  ├── 浮浅预算计算 ←─ 遍历timeline统计浮浅分钟数
  ├── 环境隔离三件套 ←─ 每次推送显示检查清单
  ├── 拖延根因诊断 ←─ runtime/_overflow_tracker.json 追踪连续overflow
  ├── ART恢复建议 ←─ 根据深度时长推荐恢复活动
  └── 每日推送含全部模块

weekly_deep_review.py（🆕 v2）
  ├── 每周日21:00自动运行
  ├── 读取追踪表生成可视化周报（ASCII柱状图+进度条）
  └── 推送到飞书

自动推送 7:00 ──→ 作战时间轴（含第一勺+浮浅预算+环境隔离+ART恢复+拖延诊断）
自动推送 周日21:00 ──→ 深度工作周报（含4DX计分板+趋势图+模式识别+职场资本）
```

## 速查

- **节奏哲学**最适合备考场景 → 默认采用
- **黄金段(09:00-12:15)** = 不可动摇的深度工作时间
- **4DX目标**：每周25h深度工作
- **浮浅预算**：不超过总时间的30%
- **第一勺冰淇淋**：每天第一件事，在处理消息前完成
- **罗斯福冲刺**：`【冲刺】`标签 → 30分钟极限专注
- **拖延诊断**：连续3天overflow → 不是时间不够，是在逃避
- **ART恢复**：深度3h+需要主动恢复（散步/手工/非屏幕）
