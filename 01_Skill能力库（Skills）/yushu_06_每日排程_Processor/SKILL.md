## 功能定位

根据精力状态、科目基线权重、任务优先级，生成当天最优任务排程时间轴。含进度条可视化、核心事件、社交/财务/创作/知识/灵感模块。

## 触发方式

`#排程` 指令 / 每日 07:00 定时推送 / 用户询问"今天安排" / 精力状态更新后自动重算。

## 输出

作战时间轴推送文本（含 stats）；可选创建今日飞书任务。

## 一、数据输入

### 1.1 从执行库获取今日待办

读取 Base 执行库，筛选条件：
- 截止日 = 今天 或 状态 ∈ {待排期, 进行中, 待收集}
- 排除 状态 ∈ {已完成, 已归档}

排序：权重降序 → 硬骨头优先 → 截止日期升序

**权重映射**：
| 优先级 | 权重 |
|--------|------|
| P0-重要紧急 | 100 |
| P1-重要不紧急 | 80 |
| P2-紧急不重要 | 60 |
| P3-不重要不紧急 | 40 |

### 1.2 读取科目进度基线

从科目进度基线表读取各科：
- 当前完成率（%）
- 平均每天应投入小时数
- 考试日期（计算倒计时用）

### 1.3 读取精力状态

从 `runtime/_energy_status.json` 读取当天精力状态。
从 `runtime/_schedule_config.json` 读取自定义配置。

## 二、时长计算

默认每日可用时长 = 10.0 小时

| 精力状态 | 系数 | 实际可用 |
|---------|------|---------|
| 好 | ×1.2 | 12.0h |
| 一般（正常） | ×1.0 | 10.0h |
| 差 | ×0.8 | 8.0h |

可通过 `#配置` 覆盖：
- `可用时长 11小时` → 今日可用时长 = 11
- `精力系数 0.9` → 在精力基础上额外调整

范围限制：最低 4h，最高 14h

## 三、时段体系

| 时段 | 时间 | 精力等级 | 时长 | 说明 |
|------|------|---------|------|------|
| 高效段① | 09:00-10:30 | 高 | 1.5h | 高效学习 |
| 休息 | 10:30-10:45 | — | 15min | 恢复精力 |
| 高效段② | 10:45-12:15 | 高 | 1.5h | 高效学习 |
| 午休 | 12:15-14:00 | — | 1.75h | 午餐+休息 |
| 完整段① | 14:00-17:00 | 中 | 3h | 可支配完整时间 |
| 休息 | 17:00-17:15 | — | 15min | 短暂放松 |
| 完整段② | 17:15-18:45 | 中 | 1.5h | 可支配完整时间 |
| 晚餐 | 18:45-20:00 | — | 1.25h | 晚餐 |
| 零散段 | 20:00-22:00 | 低 | 2h | 零散时间 |

高效总时长：3h | 完整时间：4.5h | 零散时间：2h

## 四、科目偏差驱动的动态权重

从科目基线读取数据，对每个科目计算"理论完成率 vs 实际完成率"的差距：

```
理论完成率 = 当前日期在全年中的位置（从1月1日起算）
差距 = max(0, 理论完成率 - 实际完成率)
```

差距 > 10% → 该科目任务权重 +20
差距 > 30% → 该科目任务权重 +40（上限 +50）

## 五、排程逻辑

1. 所有任务按权重降序排列（硬骨头优先）
2. 遍历每个时段，优先分配同精力等级的任务
3. 如果该精力等级没有任务，从待分配池补位
4. 任务不能跨时段拆分（一个任务必须在一个时段内完成）
5. 放不下的任务标记为"超载→移至明日"

**补位规则**：
```
高效段 优先放 高精力任务 → 没有则从中精力池取
完整段 优先放 中精力任务 → 没有则从低精力池取
零散段 优先放 低精力任务 → 没有则从中精力池取
```

## 七、子模块逻辑

### 7.1 核心事件

取今日最重要的一件任务：
1. 硬骨头中权重最高、截止最近的那个
2. 无硬骨头 → P0 中截止最近的
3. 无 P0 → 权重最高的

### 7.2 社交提醒

**生日提醒**：未来7天内的生日
**久未联系提醒**：距今未联系天数 ≥ 自适应阈值
- 亲密度 ★★★ → 7天阈值
- 亲密度 ★★ → 14天阈值
- 亲密度 ★ → 30天阈值

### 7.3 财务概览

查询财务流水表当月数据，按分类汇总支出金额，取 TOP5。

### 7.4 创作进展

查询创作素材表中状态=进行中的作品。

### 7.5 知识笔记

今日新增笔记数 + MOC 导航图数量。

### 7.6 灵感冷处理

查询灵感库中转化状态=待孵化且创建超过3天的灵感。

### 7.7 进度条

```
已排入任务数 / 今日总任务数 = 填充率
bar = █ * (20 * 填充率) + ░ * (20 * (1-填充率))
```
