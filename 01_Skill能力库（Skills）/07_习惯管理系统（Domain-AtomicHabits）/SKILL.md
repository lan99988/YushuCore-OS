# 掌控习惯 × 飞书自动化

> 将习惯四步法(提示→渴求→反应→奖赏)与四大定律落地为可执行的飞书系统

> 标准信息段（依据 `Skill规范.md` 模板）

## 基础信息

| 项 | 值 |
|------|------|
| 名称 | 习惯管理系统（Atomic Habits） |
| 版本 | 1.0（skill: atomic-habits-feishu） |
| 状态 | 稳定 |
| 创建时间 | 2026-07-01（整合） |
| 负责人 | 甲乙簿 |

## 功能定位

将《掌控习惯》四步法 + 四大定律落地为飞书习惯追踪系统。创建习惯、打卡、进度分析。

## 触发方式

`#习惯` / `#习惯打卡` / `#习惯进度`。

## 输入

`#习惯` 指令 + `【我是 / 在 / 提示 / 频率】` 变量。

## 输出

创建 / 更新习惯追踪表；打卡连续天数；进度分析。

## 依赖

- 飞书 Base（习惯追踪表）
- input_parser（路由）
- daily_scheduler（每日推送习惯专区）

## 数据

习惯追踪表（飞书 Base）。

## 权限

- read：习惯表
- write：习惯表
- admin：无

## 调用链

`#习惯` → input_parser → 飞书 Base 习惯追踪表；daily_scheduler 读取推送

## 测试

测试方式：手动 `#习惯 每天背20单词` + `#习惯打卡 背单词`。
最后测试时间：2026-07-01

## 核心映射

| 习惯概念 | 系统实现 |
|---------|---------|
| **习惯四步法** | 习惯追踪表(提示/渴求/反应/奖赏四维设计) |
| **身份驱动习惯** | 习惯追踪表「身份声明」字段 + 每日推送身份提醒 |
| **执行意图** | 习惯创建时自动提取时间+地点，构造「何时何地做」 |
| **习惯叠加** | 「习惯叠加」字段：在[已有]之后做[新习惯] |
| **环境设计** | 「提示位置」字段：记录视觉提示放在哪 |
| **两分钟规则** | 新习惯(连续≤3天)自动推送"先做2分钟版本" |
| **习惯跟踪(打卡)** | `#习惯打卡 习惯名` → 自动更新连续天数和总次数 |
| **承诺机制** | 习惯创建确认消息包含执行计划 |
| **潜能蓄积期** | 第1次打卡时推送"走出了潜能蓄积区的第一步" |
| **金发女孩准则** | 连续天数影响推送语调(7天→庆祝, 21天→里程碑) |

## 表结构

### 习惯追踪表（飞书Base）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 习惯名称 | text | 习惯名称 |
| 身份声明 | text | "我是XXX"式身份宣言 |
| 执行意图 | text | "我将在[时间]在[地点][做某事]" |
| 习惯叠加 | text | "在[现有习惯]之后，我将[新习惯]" |
| 提示位置 | text | 环境设计提示(放哪可以提醒自己) |
| 频率 | select | 每天/每周2-3次/每周1次/自定义 |
| 当前连续天数 | number | 当前打卡连续天数 |
| 历史最佳 | number | 历史最高连续天数 |
| 总打卡次数 | number | 累计打卡次数 |
| 状态 | select | 进行中/已暂停/已达成 |

## 指令参考

```
#习惯 每天背20单词
  → 创建习惯（含身份声明可选）

#习惯 每天做20个深蹲 【我是：健身者】【在午饭后】【提示：瑜伽垫铺地上】【频率：每天】
  → 创建习惯（含全部四大定律配置）

#习惯打卡
  → 查看今日全部待打卡习惯

#习惯打卡 背单词
  → 打卡指定习惯（自动:+1连续天数）

#习惯进度 背单词
  → 查看习惯详情（四步法分析+改进建议）
```

### 变量标签

| 标签 | 对应的四大定律 |
|------|--------------|
| `【我是：XXX】` | 第二定律(身份) |
| `【在：XXX】` | 第一定律(提示) |
| `【在XX之后】` | 第一定律(习惯叠加) |
| `【提示：XXX】` | 第一定律(环境设计) |
| `【频率：XXX】` | 第三定律(简化) |

## 数据流

```
用户输入 ──#习惯──→ input_parser.py ──→ 飞书Base习惯追踪表(创建)
          ──#习惯打卡──→ input_parser.py ←── 飞书Base习惯追踪表(打卡+更新连续天数)
          ──#习惯进度──→ input_parser.py ←── 飞书Base习惯追踪表(读取详情)

daily_scheduler.py
  ├── query_habits() ←─ 读取习惯追踪表(进行中)
  ├── 每日推送含习惯专区(待打卡列表+两分钟规则)
  └── 新习惯连续≤3自动提示"先做2分钟版本"

自动推送 7:00 ──→ 习惯打卡专区 + 身份提醒
```

## 四大定律检查清单

创建习惯时自动检查：

```
✅ 第一定律(提示)：是否有执行意图/习惯叠加/环境提示？
✅ 第二定律(渴求)：是否有身份声明？
✅ 第三定律(反应)：是否足够容易？频率合理？
✅ 第四定律(奖赏)：打卡后能看到天数增长 = 即时奖赏
```
