## 功能定位

当意图分类返回"不确定"或字段缺失时，通过多轮对话引导用户补充信息。每次最多问 1-2 个问题，3 轮强制退出。

## 触发方式

意图分类返回以下任一状态：`type: undefined` / `project: null` / `deadline: null` + 时间约束信号。

## 输入

部分字段 + 用户对话。

## 输出

校准后完整字段字典（`fields_complete: true`）。

## 依赖

- 飞书操作（下游）

## 纲要

当意图分类引擎返回"不确定"或关键字段缺失时，通过多轮对话引导用户补充信息。
每次最多问1-2个问题。产出校准后的完整结构化数据后，交给上游 skill 继续处理。

## 触发

「随手录-意图分类」返回任何以下状态：
- `type: undefined`（意图模糊，同时匹配多种分类特征）
- `project: null`（无法确定所属项目）
- `deadline: null` + 有明确的时间约束信号（缺少关键字段）

## 输出

补充/修正后的完整字段字典。格式同「随手录-意图分类」的产出格式。
关键字段用默认值补齐后返回。

## 一、问答模板

### 1.1 意图模糊时

用户输入同时匹配多种分类特征：

```
用户: [模糊输入]
→ 你这是要记录一个[任务/待办]，还是一个[灵感/想法/知识点]？
  或者其他？（Bug、精力状态）
用户: 是一个任务
→ （进入任务处理流程，继续检查字段完整性）
```

### 1.2 项目不明确时

```
→ 这个[灵感/任务]跟哪个项目有关？
  考研 / 项目A / 项目B / 项目C / 项目D / 生活区 / 全局
用户: 考研
→ （标记所属项目=考研）
```

### 1.3 优先级不明时

```
→ 这个任务有多紧急？
  P0-今天必须做 / P1-重要但不紧急 / P2-常规 / P3-不急
```

### 1.4 截止日不明时

```
→ 有没有截止时间？比如今天、这周末、还是自由安排？
```

### 1.5 耗时不明时

```
→ 大概需要花多少时间？（多少分钟？）
```

## 二、特殊场景处理

### 2.1 输入太短/太模糊

```
用户: "数学"
→ 是关于数学的[任务：比如要做题/复习] 还是 [灵感：比如学习方法/心得]？
  或者具体想说什么？
```

### 2.2 输入信息不全但可推断

```
用户: "今天下午刷408真题"
→ 已识别到：创建任务「刷408真题」，截止今天，属于考研项目。
  需要补充优先级或预估耗时吗？
用户: 不用
→ （直接用默认值写入）
```

## 三、边缘情况处理

| 场景 | 处理方式 |
|------|---------|
| 用户连续发送多条相似内容 | 询问是否重复，合并为一条 |
| 用户输入明显是闲聊/无关内容 | "这个好像不属于任务或灵感，需要我帮你记点什么吗？" |
| 用户输入很长（>500字） | 分段总结，提取多个要点分别归类 |
| 用户只发了一个词（"好""ok""嗯"） | 视为对上一条回复的确认，不创建新记录 |
| 用户发送表情/仅有标点 | 忽略，或确认是否没说完 |
| 同时匹配任务+灵感 | 判断主导意图，在答复中标注"另外，这个想法已记录到灵感库" |

## 四、问答效率原则

1. **每次最多问1-2个问题**，避免轰炸用户
2. **优先解决"意图类别"和"项目归属"** 这两个核心问题
3. 次要字段（优先级、耗时）仅在明显需要时询问
4. 如果用户说"就这样吧" / "直接存"，则用默认值写入
5. 已完成校准后，将补充结果返回给意图分类 skill 继续处理

## 五、强制退出条件（严格执行）

### 退出信号

满足以下**任一条件**，立即停止提问：

| # | 条件 | 触发示例 |
|---|------|---------|
| A | 用户明确说"就这样"/"直接存"/"不用了"/"够了" | "就这样吧" |
| B | 意图类别 + 所属项目均已确定 | 已知是"考研的任务"，其他缺省 | 
| C | 用户连续 2 次回答"没有""不用"或类似否定 | "不用""没了" |
| D | 已经问了 **3 轮**问题（每轮最多 2 个问题） | 3 次问答后强制退出 |

### 退出处理

达到退出条件后：

1. 用默认值填充剩余空字段：
   - 优先级 → P2-紧急不重要
   - 精力消耗 → 中
   - 预估耗时 → 留空
   - 截止日期 → 留空
   - 属于项目 → 全局（如未确定）

2. 在产出接口中标记 `exit_reason` 指明退出原因

3. 交给「意图分类」完善字段结构 → 转交「飞书操作」

### 禁止行为

- ❌ 字段补齐后还问"还有其他需要补充的吗"
- ❌ 用户说了"直接存"后还确认"确定吗"
- ❌ 超出 3 轮问题循环
