## 功能定位

处理带 `#` 前缀的结构化输入，解析前缀指令 + 提取 `【】` 变量，产出标准化字段字典。**不直接写入任何东西**。

## 触发方式

用户输入以 `#` 开头且属任一指令：`#任务 #灵感 #Bug #精力 #配置 #账单 #财务 #社交 #关系 #人脉 #创作 #作品 #知识 #笔记 #学 #孵化 #复盘`。

## 输入

自然语言（`#` 前缀 + `【】` 变量）。

## 输出

标准化字段字典 `{table, title, 所属项目, 轻重缓急, ...}` 或特殊结果（energy / config / hatch / review）。

## 依赖

- 飞书 Base（去重/复盘查询）
- 系统注册表（Token / 表 ID）
- `#精力` `#配置` 写 runtime JSON 供排程读取

## 数据

执行库、灵感库、Bug库、财务流水表、社交关系表、创作素材表、知识笔记表。

## 权限

- read：Base 查询
- write：runtime/_energy_status.json、runtime/_schedule_config.json
- admin：无

## 调用链

`#` 输入 → 输入解析引擎 → 产出 fields → 飞书操作（写）/ 排程算法（读 energy/config）/ 直接返回（review）

## 二、通用变量提取规则

用户使用 `【】` 标记结构化信息，位置自由，顺序无关：

### 2.1 所属项目

```
【项目：XX】→ PROJECT_ALIAS 映射
  #数学二 / #英语二 / #政治 / #408 → 考研
  #项目A / #项目B / #项目C / #项目D → 对应项目
  #生活区 / #全局 → 对应项目
```

自动推断科目类别（仅考研且有子科目时）：
- 输入含"数学二" → 科目类别=数学
- 输入含"英语二" → 科目类别=英语
- 输入含"政治" → 科目类别=政治
- 输入含"408" → 科目类别=专业课

### 2.2 轻重缓急

| 标记 | 映射 |
|------|------|
| `#P0` / `【紧急】` | P0-重要紧急 |
| `#P1` / `【重要】` | P1-重要不紧急 |
| `#P2`（或默认） | P2-紧急不重要 |
| `#P3` | P3-不重要不紧急 |

默认：P2-紧急不重要

### 2.3 截止日期

```
【截止：2026/07/05】→ 解析为 yyyy/MM/dd
【截止：7月5日】→ 解析为 yyyy/MM/dd（已过月→明年）
【截止：5日】→ 解析为 yyyy/MM/dd（已过日→下月）
```

### 2.4 精力消耗等级

```
【精力：高】或 #高 → 高
【精力：中】或 #中 → 中（默认）
【精力：低】或 #低 → 低
```

### 2.5 预估耗时

```
【耗时：120分钟】或 "120分钟" → 120（整数分钟）
```

### 2.6 硬骨头

```
【硬骨头】或 #硬骨头 → 是否为今日硬骨头 = true
```

### 2.7 触发场景（灵感库专用）

```
【触发场景：洗澡时】→ 记录触发场景
```

### 2.8 严重程度（Bug库专用）

```
【严重程度：崩溃】→ 崩溃
【严重程度：功能缺陷】→ 功能缺陷（默认）
【严重程度：UI优化】→ UI优化
```

### 2.9 责任人

```
【责任人：我自己】→ 我自己
【责任人：WorkBuddy】→ WorkBuddy
【责任人：随手录】→ 随手录
```

## 三、各指令专用解析

### 3.1 #账单 / #财务

格式：`#账单 午饭 28元 餐饮`

**金额提取**：
- 正则 `(\d+\.?\d*)\s*(元|块|¥|\$)?`
- 收入检测："收入""赚""工资""兼职" → 金额=负值
- 支出检测：默认 → 金额=正值

**分类匹配**：
| 关键词 | 分类 |
|--------|------|
| 饭/餐/吃/食 | 餐饮 |
| 车/行/加油 | 交通 |
| 书/课/学 | 学习 |
| 衣服/淘宝/买 | 购物 |
| 电影/游戏/玩 | 娱乐 |
| 药/医院 | 医疗 |
| 聚会/请客 | 社交 |
| 其他未匹配 | 其他 |

### 3.2 #社交 / #关系 / #人脉

格式：`#社交 见了张三 聊考研 同学 ★★★`

**联系人提取**：去掉常见动词前缀（见了/见了/找/约了/给/跟）

**活动类型推断**：
| 关键词 | 活动类型 |
|--------|---------|
| 打电话/打给/打视频 | 电话 |
| 微信/发消息 | 微信聊天 |
| 吃饭/饭局/聚餐 | 饭局 |
| 见面/碰面/约/聚会 | 见面 |
| 默认 | 其他 |

**亲密度**：`★★★`/`★★`(默认)/`★`

**生日提取**：`生日: 1996-03-15` → 写入生日字段

**关系标签**：同学/朋友/家人/同事/学长/合作伙伴

### 3.3 #创作 / #作品

格式：`#创作 公众号文章 文章 灵感`

**状态**：灵感(默认)/草稿/进行中/已完成/已发布
**类型**：文章(默认)/代码/视频/图片/设计/文档
**关联灵感**：`关联灵感: XXX`

### 3.4 #知识 / #笔记 / #学

格式：`#知识 泰勒公式展开 数学 来源:张宇P120`

**来源类型**：书籍/课程/文章/视频/经验/AI对话(默认=其他)
**来源详情**：从"来源:"后提取
**分类**：数学/英语/政治/408/编程/管理/生活(默认=其他)
**MOC检测**：含"MOC" → 类型=MOC，否则=常青笔记
**关联记录/关联灵感**：用`关联:`和`关联灵感:`提取

## 四、特殊指令处理

### 4.1 #精力

**状态分类**：
| 关键词 | 状态 | 时长调整 |
|--------|------|---------|
| 很差/不好/很差劲/疲惫 | 差 | 缩至8小时（精力系数×0.8） |
| 一般/还行 | 一般 | 默认10小时 |
| 好/很好/非常好/不错/精力充沛 | 好 | 扩展至12小时（精力系数×1.2） |

**写入**：`runtime/_energy_status.json`

### 4.2 #配置

**可配置项**：
- `黄金段 09:00-11:30` → 修改高效段时段
- `常规段 14:00-17:00` → 修改完整段时段
- `晚间段 20:00-22:00` → 修改零散段时段
- `可用时长 11小时` → 自定义今日可用时长
- `精力系数 0.9` → 自定义精力系数
- `开启/关闭 灵感提醒` → 灵感开关

**写入**：`runtime/_schedule_config.json`

### 4.3 #孵化

**用法**：
- `#孵化` → 取最新一条待孵化灵感转为任务
- `#孵化 数学二` → 过滤科目

**流程**：读取灵感库 → 筛选 `转化状态=待孵化` → 创建执行库任务 → 更新灵感库 `转化状态=已孵化`

### 4.4 #复盘

**用法**：`#复盘`（默认7天）/ `#复盘 14`（指定天数）

**流程**：读取执行库 → 过滤创建时间在回顾期内 → 统计完成率/项目分布/科目分布/优先级分布 → 生成报告

**报告输出**：
```
📊 【7天复盘报告】（06/24 - 07/01）
总任务：42 | 完成：28 | 完成率：66.7%
总耗时：1680分钟（28.0h）

按项目分布：
  · 考研：30 项
  · 项目A：8 项
  · 生活区：4 项

按科目分布：
  · 数学：12 项
  · 英语：8 项
  · 专业课：6 项
  · 政治：4 项

按优先级分布：
  · P1-重要不紧急：20 项
  · P2-紧急不重要：15 项
  · P3-不重要不紧急：7 项
```

## 五、去重检查

仅对**执行库**执行。写入前检查是否已有**同日期的同名任务**：
- 标题模糊匹配（±2字符误差容忍）
- 截止日期精确匹配
- 匹配到重复 → 跳过创建，返回去重提示
