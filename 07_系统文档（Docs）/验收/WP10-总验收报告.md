## 用户成本验收

- Capture 普通任务和社交承诺都只需一次自然语言输入，不要求填表。
- Social 一次互动输入完成 Person、Interaction、Commitment 的待审提取。
- Finance 每月一次截图引用即可生成聚合快照与分析提案。
- dormant 领域没有真实事件时不创建记录、不要求维护。
- Today 输出明确分成硬约束、建议、自动调整和待确认项。
- 用户可见建议均带 `reason_code`；Personal Rule 建议带规则 ID、证据引用和置信度。

## 安全验收

安全与恢复定向测试已被最终完整门禁覆盖，达到 `957 passed + 47 subtests`。

- 外部消息、外部承诺和固定会议变化未经批准不执行。
- 支付、转账、投资和不可逆删除受策略禁止或审批约束。
- Agent 自治等级上限为 2，默认网络模式为 OFF，Agent 不直接访问 Vault。
- Runtime 事件和审计不记录凭证、知识正文、财务截图正文、健康原始数据或完整外部消息正文。
- 插件 disabled/dormant/unavailable 时 Planner/Executor fail-closed，不留下隐式后台动作。

## 恢复验收

- 单插件禁用不阻止 Runtime 和其他 ready 插件启动。
- 单步骤失败会返回 partial/failed/blocked，不会冒充 completed。
- 自动调整包含 before/after；固定会议 before/after 相同。
- 只有实际调用补偿回调时才发 rollback 事件；离线补偿标为 simulated。
- 无法物理回滚的外部写入必须进入 Runbook 的人工补偿清单。
- 迁移矩阵保留旧入口；本轮未删除 legacy path。
