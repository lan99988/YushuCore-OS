## 一、集成策略总览

### 映射关系

| 习惯概念 | 系统组件 | 实现方式 |
|---------|---------|---------|
| **习惯四步法** | 习惯追踪表 | 提示→渴求→反应→奖赏 四个字段记录 |
| **身份驱动习惯** | #习惯 指令 + 推送 | 身份声明字段 + 每日推送"身份提醒" |
| **执行意图** | 习惯公式字段 | `我将于[时间]在[地点][做某事]` |
| **习惯叠加** | 习惯追踪表 | 「在XX之后做XX」字段绑定已有习惯 |
| **环境设计** | 习惯追踪表 | 「提示位置」字段记录 |
| **两分钟规则** | 每日排程推送 | 新习惯自动提示"先做2分钟版本" |
| **习惯跟踪(打卡)** | #习惯打卡 + 追踪表 | 每日一条打卡记录，自动计算连续天数 |
| **承诺机制** | #习惯 指令 | 创建习惯时自动生成习惯契约 |
| **金发女孩准则** | 排程提醒 | 基于连续天数推荐难度调整 |
| **潜能蓄积期** | 推送消息 | 连续天数低时推送"你在蓄积能量"鼓励 |

### 新表：习惯追踪表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 习惯名称 | text | 习惯的名称 |
| 身份声明 | text | "我是XXX"式身份宣言 |
| 执行意图 | text | "我将于[时间]在[地点][做某事]" |
| 习惯叠加 | text | "在[现有习惯]之后，我将[新习惯]" |
| 提示位置 | text | 环境设计方案（放在哪里提醒自己） |
| 频率 | select | 每天/每周N次/自定义 |
| 当前连续天数 | number | 当前打卡连续天数 |
| 历史最佳 | number | 历史最高连续天数 |
| 总打卡次数 | number | 累计打卡次数 |
| 状态 | select | 进行中/已暂停/已达成 |
| 创建时间 | created_at | 自动 |
| 最后修改时间 | updated_at | 自动 |

## 三、Scheduler 增强

### 每日推送新增「习惯专区」

```
📋 【今日习惯打卡】
  · 🔲 背单词（🔥已连续7天）- 身份：我是背词者
  · 🔲 做20个深蹲（新习惯！先做2个→两分钟规则）
```

### 关键逻辑

1. 读取习惯追踪表中状态=进行中的习惯
2. 检查今天是否已打卡（追踪表记录）
3. 未打卡的显示 🔲 待打卡
4. 已打卡的显示 ✅ 已打卡
5. 新习惯连续天数≤3 → 自动附两分钟规则提示
6. 全部打卡完成 → 推送"今天已全部打卡！"
7. 每7天连续 → 推送"里程碑！已连续7天"

---

## 四、自动打卡检测

在 `#习惯打卡` 指令中：
1. 解析习惯名后查追踪表找到对应记录 ID
2. 写一条打卡记录到打卡记录暂存区
3. 更新追踪表中的当前连续天数和总打卡次数
4. 如果连续天数 > 历史最佳，更新历史最佳
