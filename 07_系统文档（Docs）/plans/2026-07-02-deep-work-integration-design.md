# 深度工作法 - 系统集成设计

> 将卡尔·纽波特的《深度工作》方法论融入个人混合管理系统
> 2026-07-02 | 基于节奏哲学 + 执行四原则

---

## 一、集成策略总览

### 映射关系

| 深度工作概念 | 系统组件 | 实现方式 |
|-------------|---------|---------|
| **节奏哲学** | daily_scheduler | 黄金段升级为深度工作时段，每天固定4段深度时间 |
| **执行四原则** | 深度工作追踪表 + Scheduler | 引领性指标(深度小时数) + 计分板(周累计) + 问责 |
| **时间块计划法** | daily_scheduler (增强) | 每个时段标注深度/浮浅属性 |
| **罗斯福冲刺** | input_parser + 执行库 | `【冲刺】` 标签 → 任务标记为冲刺模式 |
| **浮浅工作预算** | scheduler超载逻辑 | 浮浅工作不超过30%的约束（自动控制） |
| **艺人的方法** | #深度 指令 | 工具使用评估框架 |
| **拥抱无聊** | 推送消息 | 深度工作开始前提醒"关机" |
| **度量黑洞** | 深度工作追踪表 | 量化每日深度/浮浅时间 |

### 新表结构：深度工作追踪表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 日期 | datetime | 每日一条 |
| 当日深度工作时长(min) | number | 当日深度工作时长（分钟） |
| 计分板周累计深度(h) | number | 本周累计深度小时数（4DX引领性指标） |
| 当日浮浅工作占比 | number | %（0-100） |
| 最高心流状态 | select | 无/低/中/高/巅峰 |
| 干扰次数 | number | 当日被干扰的次数 |
| 当前深度哲学 | select | 节奏哲学(默认)/双峰哲学/记者哲学/禁欲主义 |
| 冲刺任务数 | number | 当日罗斯福冲刺次数 |
| 备注 | text | 当日总结/改进点 |

## 二、指令扩展

### 新增前缀指令

| 指令 | 功能 | 示例 |
|------|------|------|
| `#深度规划` | 设定当天深度工作目标 | `#深度规划 深度4小时 浮浅1小时` |
| `#深度记录` | 记录当天的深度工作表现 | `#深度记录 心流巅峰 干扰2次` |
| `#深度` | 深度工作通用入口(自动判断意图) | `#深度 今天状态好 冲刺3个` |

### 新增标签（镶嵌在现有指令中）

| 标签 | 功能 | 解析 |
|------|------|------|
| `【冲刺】` | 标记罗斯福冲刺任务 | 自动设定预估耗时=30min，精力=高 |
| `【深度：N】` | 标记任务深度分数(1-10) | 用于统计深度工作占比 |

### 新增 #复盘 子命令

| 命令 | 功能 |
|------|------|
| `#复盘深度` | 深度工作专项复盘（过去7天深度数据） |
| `#复盘深度 14` | 指定天数 |

## 三、Scheduler 增强

### 3.1 时段重新标记

将 SLOT_LAYOUT 新增 `mode` 属性：

| 时段 | 原标记 | 新模式标记 |
|------|--------|-----------|
| 高效段① 09:00-10:30 | 高效学习 | **🔴 深度工作** |
| 高效段② 10:45-12:15 | 高效学习 | **🔴 深度工作** |
| 完整段① 14:00-17:00 | 可支配完整时间 | 🟡 深度工作(可选) |
| 完整段② 17:15-18:45 | 可支配完整时间 | 🟡 浮浅工作优先 |
| 零散段 20:00-22:00 | 零散时间 | 🟢 浮浅工作 |

### 3.2 4DX计分板逻辑

1. **极端重要的事（WIG）**：今日核心事件（已有）
2. **引领性指标**：今日深度工作小时数
3. **计分板**：本周累计深度小时数（从深度工作追踪表读取）
4. **问责**：每日推送末尾附计分板状态

### 3.3 罗斯福冲刺自动检测

检测 `【冲刺】` 标签的任务：
- 自动分配早深度工作时段
- 强制缩减预估耗时到30分钟（或用户指定）
- 推送时添加 🔥 冲刺标记
