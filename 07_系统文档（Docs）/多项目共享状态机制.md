# 多项目共享状态机制

> 让所有项目通过同一套飞书Base实现多Agent无感协作

---

## 一、状态流动图

```
┌─────────────────────────────────────────────────────┐
│                   飞书Base（状态中枢）                  │
│                                                      │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐          │
│  │ 项目管理表 │  │  执行库   │  │ 灵感库/  │          │
│  │(总控台)   │  │(任务池)   │  │ Bug库    │          │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘          │
│       │              │              │                │
│       ▼              ▼              ▼                │
│  ┌─────────────────────────────────────┐            │
│  │  每条记录都有：责任人 + 状态 + 时间戳   │            │
│  └─────────────────────────────────────┘            │
│                                                      │
│  Agent A ──── 只读「责任人=A, 状态=待收集」────────      │
│  Agent B ──── 只读「责任人=B, 状态=待收集」────────      │
│  daily_scheduler ─── 每天聚合全部Agent进展 → 推给你     │
└─────────────────────────────────────────────────────┘
```

## 三、跨项目数据流示例

### 场景1：随手录在日常工作中收集到股市策略灵感和Bug

```
你：  #灵感 K线形态识别新方法 【项目：股市策略】【责任人：随手录】
     → 灵感库新增一条：状态=待收集，责任人=随手录
     
你：  #Bug 数据源连接超时 【项目：股市策略】【责任人：随手录】
     → Bug库新增一条：状态=待收集，责任人=随手录

随手录下次启动 → 读到责任人=自己的记录 → 处理
```

### 场景2：多个Agent协作同一个项目

```
你：  #任务 实现模块A 【项目：股市策略】【责任人：随手录】
     #任务 实现模块B 【项目：股市策略】【责任人：WorkBuddy】
     #任务 实现模块C 【项目：股市策略】【责任人：我自己】
     → 执行库新增3条，各自标记责任人

随手录 → 只拿「责任人=随手录 AND 状态=待收集」的任务
WorkBuddy → 只拿「责任人=WorkBuddy」的任务
你 → 只看到「责任人=我自己」的任务

完成后各Agent更新状态=已完成
daily_scheduler 次日推送：今日完成了3/3任务
```

### 场景3：一个项目卡住了，另一个Agent接手

```
Agent A 遇到阻塞 → 在项目管理表中填写「阻塞原因」
你看到推送：「项目X阻塞：等待API文档」

Agent B 启动时看到「阻塞原因」有值且自己可以帮上
Agent B 接手 → 更新负责Agent = Agent B
处理完成后清除「阻塞原因」
```

## 四、每条记录的责任人标签

| 表 | 是否支持责任人 | 如何输入 |
|:---|:------------:|:---------|
| 📋 执行库 | ✅ | `#任务 ...【责任人：随手录】` |
| 💡 灵感库 | ✅ | `#灵感 ...【责任人：随手录】` |
| 🐛 Bug库 | ✅ | `#Bug ...【责任人：WorkBuddy】` |
| 💰 财务流水表 | ❌ 不需要 | 谁花钱不重要 |
| 🤝 社交关系表 | ❌ 不需要 | 见朋友不分配Agent |
| 🎨 创作素材表 | ❌ 不需要 | 创作一般你自己做 |
| 📝 知识笔记表 | ❌ 不需要 | 知识归你自己 |

## 五、Agent启动清单（通用版，适用于所有项目）

每个Agent在处理任何项目时：

```
1. 读配置
   base_token = TtzIboiQQaPgfVszO2vc56wLnof
   身份 = --as=user

2. 查自己的待办（不限项目，跨所有表）
   执行库：责任人=自己 AND 状态∈{待收集,待排期}
   灵感库：责任人=自己 AND 状态∈{待收集}
   Bug库： 责任人=自己 AND 状态∈{待收集,待修复}

3. 领任务
   更新状态=进行中
   更新时间戳

4. 执行 + 完成
   更新状态=已完成
   或填写阻塞原因
```
