### 变量提取标记

用户在消息中使用以下标记结构化输入（位置自由，顺序无关）：

```
#任务 做数学真题2010 【项目：数学二】【精力：高】【耗时：120分钟】【截止：2026/07/05】
```

| 标记 | 对应字段 | 默认值 |
|------|---------|--------|
| `【项目：XXX】` 或 `#数学二` | 所属项目 | — |
| `#P0`~`#P3` 或 `【紧急】` | 轻重缓急 | P2-紧急不重要 |
| `【截止：XXX】` | 截止日期（支持 7月5日 或 2026/07/05） | — |
| `【精力：高/中/低】` 或 `#高/#中/#低` | 精力消耗等级 | 中 |
| `【耗时：XX分钟】` | 预估耗时（整数，单位：分钟） | — |
| `【硬骨头】` | 是否为今日硬骨头 = true | false |
| `【触发场景：XXX】` | 触发场景（灵感库专用） | — |
| `【严重程度：崩溃/功能缺陷/UI优化】` | 严重程度（Bug库专用） | 功能缺陷 |

### 自动推断规则

- **所属项目→科目类别**：数学二→数学、英语二→英语、政治→政治、408→专业课
- **新记录默认状态**：待收集
- **超载处理**：当日任务预估耗时总和 > 可用时长，权重分从低到高顺延至次日

### 精力状态处理

`#精力 今天状态很差/一般/很好`
- 状态很差 → 次日可用时长从10h缩减为8h
- 状态很好 → 不缩减

### 配置动态调整

`#配置 黄金段 08:30-11:30`
`#配置 今日可用时长 9小时`
`#配置 关闭灵感提醒`

## 每日排程算法

### 时段-精力映射

| 时段 | 精力等级 | 用途 |
|------|---------|------|
| 黄金段 09:00-11:30 | 高 | 优先安排硬骨头任务 |
| 常规段 14:00-17:00 | 中 | 刷题/整理笔记 |
| 晚间段 20:00-22:00 | 低 | 背单词/看政治视频 |

### 任务排序规则

1. 权重分降序（P0=100, P1=80, P2=60, P3=40）
2. 同权重按截止日期升序（越近越优先）
3. 无截止日期排最后
4. 考研任务额外匹配精力等级与时段

### 推送结构

Agent每日7:00推送，格式如下：
```
【今日作战时间轴】
09:00-11:30 黄金段：XXX（120分钟）
14:00-17:00 常规段：XXX（90分钟）
20:00-22:00 晚间段：XXX（60分钟）

【硬骨头提醒】
今日必啃：XXX

【风险预警】
⚠️ 即将逾期：XXX
⚠️ 科目滞后：数学（完成率35%，应达50%）

【灵感冷处理】
📌 3天未处理灵感：XXX（请决策）
```

### 每周复盘（周日21:00）

统计完成率、各科投入占比、精力匹配度，生成3条调整建议。
用户回复"是"后，下周排程自动应用新规则。
