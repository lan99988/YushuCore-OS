## 三、仪表盘组件设计

在飞书Base中创建「仪表盘」视图，添加以下组件：

### 组件1：4DX计分板（仪表盘图）

- **类型**：仪表盘图（Gauge Chart）
- **数据源**：`计分板周累计深度(h)`
- **聚合方式**：最新值（取最近一条记录）
- **目标值**：25h
- **颜色区间**：
  - 0-12.5h：红色（不达标）
  - 12.5-20h：黄色（接近）
  - 20-25h+：绿色（达标）

### 组件2：每日深度时长趋势（折线图）

- **类型**：折线图
- **X轴**：`日期`
- **Y轴**：`当日深度工作时长(min)`（转换为小时显示）
- **聚合**：按天分组，取值
- **目标线**：180分钟（3小时）
- **颜色**：红色线

### 组件3：浅层工作占比（柱状图）

- **类型**：柱状图
- **X轴**：`日期`
- **Y轴**：`当日浮浅工作占比`
- **警戒线**：30%
- **颜色**：
  - ≤30%：绿色
  - >30%：红色

### 组件4：心流状态分布（环形图）

- **类型**：环形图（Donut Chart）
- **数据源**：`最高心流状态`
- **聚合**：计数
- **颜色映射**：
  - 巅峰：紫色
  - 高：绿色
  - 中：橙色
  - 低：红色
  - 无：灰色

### 组件5：第一勺完成率（进度条）

- **类型**：指标卡（KPI Card）
- **数据源**：`第一勺完成`（checkbox）
- **聚合**：最近7天中 true 的占比
- **显示**：百分比 + 进度条

### 组件6：干扰次数趋势（柱状图）

- **类型**：柱状图
- **X轴**：`日期`
- **Y轴**：`干扰次数`
- **颜色**：黄色
- **警戒线**：3次

### 组件7：冲刺任务统计（数字卡片）

- **类型**：指标卡
- **数据源**：`冲刺任务数`
- **聚合**：最近7天求和
- **显示**：总冲刺次数

### 组件8：恢复活动记录（列表）

- **类型**：表格视图
- **数据源**：`恢复活动` + `日期`
- **筛选**：恢复活动不为空
- **排序**：日期降序

## 五、自动更新机制

- `#深度记录 深度3.5h 心流高 干扰1次 恢复活动：散步20min 第一勺完成`
- 每周日21:00自动推送周报（`weekly_deep_review.py`）
- 每日7:00推送含深度工作模块的作战时间轴

仪表盘会随数据写入自动刷新，无需手动操作。
