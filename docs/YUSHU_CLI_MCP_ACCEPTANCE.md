# Yushu-OS CLI／MCP／IMA 升级验收记录

记录日期：2026-09-28。范围：`codex/yushu-cli-mcp-ima` 分支；尚非生产发布签字。

## 已验证的交付

- Windows 本地 Profile：无外部账号时可通过 CLI 执行六条逻辑链的本地基础路径；任务、目标等记录存入 SQLite，重启后仍可读取。目标分析、自动排程等高级决策未实现，不能将“逻辑链有基础入口”理解为全功能完成。
- 统一应用入口：CLI 和本地 stdio MCP 共用 `YushuApplication`、插件清单、权限判断与审批。所有登记能力可发现；未接线的能力返回 `plugin_executor_missing`，IMA 未配置返回 `not_configured`。MCP 不提供审批工具。
- 人工审批：承诺及标记为固定会议的本地写入需审批。待审列表提供动作内容、目标、摘要及失效时间，审批记录持久化且只能领取一次。审批仅有本机 CLI 确认门槛，尚未建立针对同一 Windows 账户下不可信进程的强身份隔离。
- IMA 知识网关：支持受权限过滤的搜索、列表、已获授权条目正文获取；列表按 IMA 每页 50 条限制分页。最多读取 5 页，超过则标记 `partial`。本地仅缓存已授权摘要和引用；正文不入缓存。断线可返回已有摘要，并携带同步时间、`stale`、`partial` 和“结果可能不完整”。本地 Markdown 不参与在线知识查询或写入。
- 数据：本地业务库可备份与恢复；旧业务数据迁移支持预览、备份后幂等导入；旧知识只做清单预览，不上传正文。恢复范围是本地业务 SQLite，并非 Profile 配置、IMA 摘要缓存或外部系统数据的整包恢复。
- 输入与外部写入防护：文件 Capture 限于 Profile 的 `imports` 中 `.txt`／`.md`；网页 Capture 限于显式许可的公开 HTTPS 域名并限制大小及跳转。飞书写入在新入口默认关闭；模拟客户端下验证幂等和失败条件，缺少真实客户端绝不报告提交成功。
- 便携包：PyInstaller 构建 Windows ZIP，包内不含 Python 安装器。独立解压目录完成初始化、任务写入、重启读取、MCP `server/discover` 握手。解压文件名扫描未见本地凭证、Profile、数据库、LLM Wiki 或 Obsidian 文件。

## 未通过／未验证的发布门槛

- IMA 凭证在此工作树不可用；此前真实只读探测返回 HTTP 401。搜索、列表、正文获取仅通过模拟适配器与契约测试，恢复凭证后须完成真实只读验收。
- 飞书日历此前真实探测为鉴权类错误；新 CLI/MCP 运行核心尚未装配飞书任务／日历权威源。选择飞书为权威源时不得回退到本地写入或报告完整结果。
- Garmin 新运行入口尚未装配；既有同步脚本及其测试不能替代新入口的真实只读验收。Ollama 健康探测在此机返回 `provider_unavailable`。
- 外部生产写入未在隔离空间真实测试。状态只能是“模拟服务契约通过，生产写入未验证”，不能标为全面可用。
- 尚未完成独立干净 Windows 主机的安装、重启、恢复和 Agent 接手全流程验证；目前是在现有 Windows 主机的独立解压目录测试。
- MCP 本地 stdio 尚未做不可信同账户进程的强身份认证或负载／限流验收，不能开启远程 HTTP 服务。

结论：本地核心和便携运行路径已有可测基础；外部接入与生产发布仍未满足计划中的全部验收标准。
