## 三、指令解析规范（供 Agent 使用）

### 前缀指令

| 前缀 | 目标表 |
|------|--------|
| `#任务` | 执行库 |
| `#灵感` | 灵感库 |
| `#Bug` | Bug库 |
| `#精力` | 精力状态记录（不写表，调节可用时长） |
| `#配置` | 推送配置修改 |
| `#账单` / `#财务` | 财务流水表 🆕 |
| `#社交` / `#关系` / `#人脉` | 社交关系表 🆕 |
| `#创作` / `#作品` | 创作素材表 🆕 |
| `#知识` / `#笔记` / `#学` | 知识笔记表 🆕 |

### 变量提取规则

```
#任务 做数学真题2010 【项目：数学二】【精力：高】【耗时：120分钟】【截止：2026/07/05】
```

支持的变量标记：
- `【项目：XXX】` 或 `#项目名` → 所属项目
- `【紧急】` 或 `#P0` → 轻重缓急
- `【截止：X月X日】` 或 `【截止：XXXX/XX/XX】` → 截止日期
- `【精力：高/中/低】` → 精力消耗等级（默认：中）
- `【耗时：XX分钟】` → 预估耗时

### 默认值规则

- 无轻重缓急标注 → 默认 `P2-紧急不重要`
- 无精力标注 → 默认 `中`
- 状态新记录 → 默认 `待收集`

## 四、每日排程算法（供 Agent 实现）

### 时间轴映射

| 时段 | 精力等级 | 说明 |
|------|---------|------|
| 09:00-11:30 黄金段 | 高 | 优先安排硬骨头任务 |
| 14:00-17:00 常规段 | 中 | 刷题/整理笔记 |
| 20:00-22:00 晚间段 | 低 | 背单词/看政治视频 |

### 排序规则

1. 权重分（P0 > P1 > P2 > P3）
2. 同权重按截止日期升序
3. 无截止日期排最后
4. 考研任务额外考虑精力等级匹配度

### 超载处理

累计预估耗时 > 可用时长 → 权重分从低到高顺延至次日

### 精力状态调整

`#精力 今天状态很差` → 次日可用时长从10小时缩减为8小时
